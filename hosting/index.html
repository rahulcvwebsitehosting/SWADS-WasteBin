Smart waste management

SWADS

The Smart Waste Alert and Dispatch System connects monitored waste bins with owners, real-time status, clearance alerts, and responsible local contacts.

How it works

  • Register and monitor an authorised smart-bin device.
  • Track fill level and alert status from the Android app.
  • Notify the signed-in owner and send clearance requests when a bin reaches the alert threshold.
  • Record reset and clearance events for operational visibility.

Google account access

SWADS uses Google Sign-In for authentication. With the user's explicit consent, it requests only the Gmail permission needed to send waste-clearance emails on that user's behalf. It does not read inbox messages.
